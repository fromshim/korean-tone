# 번역투 전체 카탈로그

영어·일본어 직역에서 오는 어색한 한국어(번역투) 목록. SKILL.md 1부의 확장판이다.
**A**는 `tone-linter` 훅이 자동 검출하는 패턴, **B**는 문맥 판단이 필요해 규칙으로만 남긴 것.

근거: 국립국어원 새국어생활 22-1 "번역과 국어"(김순영·김한식), 이오덕 『우리글 바로쓰기』,

## A. 자동 검출 (린터가 잡음)

### A-1. error 급 — 오탐 거의 없음, 보이면 거의 항상 고칠 것

| 패턴 | 지양 → 지향 |
|------|------------|
| **~에 의해** (수동 by) | "이 함수는 스케줄러**에 의해** 호출된다" → "스케줄러**가** 이 함수를 호출한다" |
| **~을 필요로 하다** (need) | "이 API는 토큰**을 필요로 한다**" → "이 API**엔** 토큰**이 필요하다**" |
| **가지다** (have 직역) | "회의**를 가졌다**" → "회의**했다**" / "메서드**를 가진다**" → "메서드**가 있다**" |
| **~에 있어서** (における) | "최적화**에 있어서** 캐싱은 중요하다" → "최적화할 **때** 캐싱이 중요하다" |
| **~에 다름 아니다** | "중복 구현**에 다름 아니다**" → "중복 구현**일 뿐이다**" |
| **~임에 틀림없다** | "캐시 문제**임에 틀림없다**" → "캐시 문제**가 분명하다**" |
| **~에도 불구하고** | "재시도했**음에도 불구하고** 실패" → "재시도했**지만** 실패" |
| **~하지 않으면 안 된다** (이중부정) | "돌리**지 않으면 안 된다**" → "**돌려야 한다**" |
| **~해도 지나치지 않다** | "강조**해도 지나치지 않다**" → "**꼭 해야 한다**" |
| **~에 위치하다** (be located) | "루트**에 위치한다**" → "루트**에 있다**" |
| **이중피동** (~되어지다/~여지다) | "개선**되어졌다**" → "**개선했다**", "**보여진다**" → "**보인다**" |
| **~이 이루어지다 / 요구되다** | "검증**이 이루어진다**" → "검증**한다**", "재시작**이 요구된다**" → "재시작**해야 한다**" |
| **그녀 / 당신** | 기술 문서의 "그녀"는 영어 번역체. "그"를 쓰거나 이름을 반복. "당신"은 대부분 생략 |
| **본(本) ~** (일본식) | "**본** 문서에서는" → "**이** 문서에서는" |
| **가장 ~한 것 중 하나** | "**가장** 흔한 원인 **중 하나**" → "흔한 원인이다 / 대표적인 원인이다" |

### A-2. warn 급 — 정당한 용례 있음, 빈도가 높을 때만 경고

한 번은 괜찮다. 문서 안에서 반복되면 줄인다.

| 패턴 | 메모 |
|------|------|
| **~에 대해 / ~에 관해** | 대부분 뺄 수 있다. "X에 대해 알아보자" → "X를 알아보자" |
| **~를 통해** | "캐싱을 통해 성능 향상" → "캐싱하면 성능이 오른다" |
| **~하기 위해** | "제거하기 위해" → "제거하려고". 문서당 2~3회 넘으면 경고 |
| **~의 경우** | "저의 경우에는" → "저는" |
| **~것이다 / ~할 수 있다** | 강조·가능 용법은 정당하나 도배 금지. 문단에 2개↑면 절반은 동사 종결로 |
| **메타 담화** | "다음과 같습니다 / 살펴보겠습니다 / 결론적으로 / 아시다시피 / 앞서 설명했듯이" → 대개 통째로 삭제 |

## B. 판단 필요 (규칙으로만, 자동 검출 안 함)

오탐이 커서 린터에 넣지 않는다. 눈으로 판단한다.

| 패턴 | 규칙 |
|------|------|
| **'~들' 남발** | "많은/여러" 등 수량 표현이 이미 있으면 '들'을 뺀다. 무정물(파일들·설정들·데이터들)의 '들'은 대부분 뺄 수 있다 |
| **'~적(的)' 남발** | 한 문장에 '~적'이 2개↑면 하나는 푼다. '~적인 것' 꼴은 거의 군더더기 |
| **'~화(化)/~성(性)' 남발** | 동사로 풀 수 있으면 푼다: "모듈화를 진행" → "모듈로 쪼갠다" |
| **대명사(그/그것/이것) 남발** | 대명사 대신 명사를 반복하거나 주어를 생략. "그것은"으로 문장을 시작하지 않는다 |
| **단발 관형격 '의'** | "서버의 설정"은 자연스럽다. '의'가 한 구에 2번 연달아면 앞엣것을 동사·주격으로 (린터가 연쇄 '의'만 잡음) |
| **일반 피동문** | 한국어 피동 자체는 정상. 행위 주체를 아는 피동만 능동으로: "설정이 완료되어야 합니다" → "설정을 완료하세요" |
| **일본식 쉼표 남용** | 주어 뒤·접속부사 뒤 습관성 쉼표를 뺀다: "저는, 어제, 재시작했습니다" → "저는 어제 재시작했습니다" |
| **일본식 한자어** | 우리말 관용 표현으로 (예: '행방불명' → '실종') |

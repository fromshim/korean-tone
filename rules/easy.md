# Easy 모드 추가 규칙

초등학생도 따라올 수 있을 만큼 쉽게 설명하되, 아기처럼 대하거나 정확성을 낮추지 않는다.

- 먼저 `무슨 일인지`를 한두 문장으로 말한다. 그다음 `왜 그런지`, 마지막에 `어떻게 하면
  되는지`를 설명한다.
- 한 문장에는 핵심 하나만 담고, 짧은 문장을 쓴다.
- 어려운 용어는 쉬운 말로 먼저 설명한 뒤 필요하면 원래 이름을 괄호에 붙인다.
- 눈에 보이는 예나 짧은 비유가 실제 이해를 도울 때만 쓴다. 비유 뒤에는 실제 동작도 말한다.
- 중간 단계를 생략하지 않는다. `A라서 C`가 아니라 필요한 경우 `A 때문에 B가 되고, 그래서
  C가 된다`고 잇는다.
- `쉽죠?`, `이것도 모르겠다면`, `아주 간단해요`처럼 독자를 평가하거나 낮춰 보지 않는다.
- 코드 식별자와 오류 원문은 그대로 둔다.
